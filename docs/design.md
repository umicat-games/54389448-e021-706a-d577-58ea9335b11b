# 坦克大战 — 游戏设计文档

## 概念

俯视角像素风坦克大战。玩家驾驶坦克守卫基地，击败一波又一波的敌方坦克。关卡难度递增，消灭所有敌人即可过关；基地被摧毁或玩家坦克被击毁三次则游戏结束。

## 核心循环

1. 玩家坦克出现在地图中央附近，基地（鹰标）位于地图底部中心
2. 敌方坦克从地图上方三个位置轮流刷新
3. 玩家移动、瞄准、射击敌人；敌人会主动向玩家或基地移动并发射炮弹
4. 消灭本关全部敌方坦克 → 进入下一关（敌人数量/速度提升）
5. 玩家或基地被击毁 → 游戏结束，显示得分

## 设计支柱

- **经典致敬**：还原 FC 坦克大战的核心玩法节奏（移动、射击、保护基地）
- **现代像素质感**：更丰富的颜色层次、粒子爆炸效果、流畅的 tween 动画
- **紧张递进**：每关敌人数量+1，速度和炮弹频率小幅提升，始终保持挑战感

## 系统设计

### 玩家坦克
- 上下左右移动（方向键 / WASD）
- 空格键射击（有射击冷却，防止无限连射）
- 最多 3 条命；被击中扣一条命，重新出生有 2 秒无敌时间
- 每关开始时满血复活（命数延续）

### 敌方坦克
- 从地图顶部左、中、右三个刷新点依次出现
- AI 行为：随机移动 + 定时朝玩家/基地方向射击
- 每关固定敌人总数（第 1 关 6 辆，每关 +2，上限 20）
- 敌方坦克分普通（绿色）和强化（红色，需击中两次）两种

### 地图
- 固定俯视角地图，1280×720 像素
- 地图元素：砖墙（可被炮弹摧毁）、钢墙（不可摧毁）、草地（遮挡坦克但不阻碍）、基地（鹰标，被摧毁即 Game Over）
- 关卡共用同一张地图，不做随机生成

### 道具（后续可扩展）
- 击败闪光敌人（随机刷新）可掉落道具：
  - 星星：升级炮弹速度
  - 头盔：无敌 10 秒
  - 铲子：基地周围临时出现钢墙保护

## 得分系统
- 击败普通坦克：100 分
- 击败强化坦克：200 分
- 关卡通关奖励：500 分
- 最高分通过平台存档持久化

## 操控
| 动作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 射击 | 空格键 |

## 视觉方向

现代像素风：
- 整体色调为军绿 / 沙漠黄 / 钢灰，地图背景深灰
- 所有游戏对象用 Phaser Graphics API 绘制（像素色块 + 高光描边）
- 炮弹命中：橙红色粒子爆炸 + 屏幕轻微震动
- 基地被击中：红色闪烁 + 更大爆炸效果

## 音频方向（可选扩展）
- 背景音：低沉的军事风循环音乐
- 音效：射击、爆炸、关卡完成、Game Over
